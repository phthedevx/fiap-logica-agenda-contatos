# 📇 Agenda de Contatos - Nivelamento FIAP

Este repositório contém o primeiro projeto desenvolvido para o módulo de **Lógica de Programação** do curso de Engenharia de Software na **FIAP**. O objetivo do desafio é aplicar conceitos básicos de lógica e algoritmos através de um sistema de gerenciamento de contatos.

## 🚀 O Desafio
Criar uma agenda de contatos que permita realizar as operações básicas de gerenciamento (CRUD) via console.

### Informações do Contato:
- Nome
- Número de Telefone
- E-mail

### Funcionalidades do Menu:
1. **Adicionar contato**: Cadastrar um novo registro.
2. **Editar contato**: Atualizar informações de um contato existente.
3. **Pesquisar contato**: Localizar um contato específico pelo nome.
4. **Listar contatos**: Exibir todos os contatos salvos.
5. **Excluir contato**: Remover um contato da lista.
6. **Sair**: Encerrar a aplicação.

## 🛠️ Tecnologias e Conceitos
Embora o curso apresente a lógica de forma genérica (Java/Python), este projeto foi implementado utilizando **Java** com foco em **Programação Orientada a Objetos (POO)**, aplicando:
- Encapsulamento (Classes e Atributos).
- Coleções (`List` e `ArrayList`).
- Manipulação de fluxos com `Scanner`.
- Estruturas de repetição e condicionais.

## 📖 Como executar
1. Certifique-se de ter o JDK instalado.
2. Clone o repositório.
3. Compile o arquivo principal: `javac Main.java`.
4. Execute a aplicação: `java Main`.
